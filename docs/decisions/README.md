# Decision records

Short notes on choices that were made deliberately and would otherwise be
invisible — where the reasoning matters more than the diff, and where the next
person's first question will be "why is it like this?".

One file per decision. A decision that is later reversed keeps its record, with
the reversal appended: the reasoning that turned out to be wrong is worth more
than a tidy history.

Not every choice needs one. These are for the ones where a reasonable engineer
would otherwise assume an oversight.
